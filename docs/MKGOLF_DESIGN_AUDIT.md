# MKGOLF 视觉与结构分析

来源：https://www.mk.golf/  
参考时间：2026-08-06  
站点类型：韩国高端高尔夫服饰 WooCommerce 电商

## 一、整体气质

- **定位**：高端/轻奢高尔夫生活方式，强调品牌感与时尚感
- **视觉调性**：极简、干净、大图、粗体字、大量留白
- **核心配色**：白底 + 黑字 + **荧光黄/青柠绿**强调色 + 浅灰卡片背景
- **品牌感知**：字母 Logo（MK 倾斜体）、全幅模特生活照、奢侈品级产品图

## 二、顶部公告栏

- **样式**：整条荧光黄/青柠绿背景，黑色韩文小字
- **内容**：直播预告（"유튜브 라이브 매일 저녁8시"）
- **适配建议**：保留可配置公告栏组件，改成英文促销文案（如"Free Shipping on Orders Over $X"），颜色保持黄黑对比

## 三、Header

- **背景**：白色（或透明覆盖在 Hero 图上）
- **左侧**：粗体斜体字母 Logo（MK）
- **中间导航**：居中的极简一级菜单
  - 국낸배송 / 신상품 / 여자 ▾ / 남자 ▾ / 액세사리 ▾ / 브랜드 ▾ / SALE / 이벤트리스트
- **右侧**：购物车图标、搜索图标、登录/注册文字入口
- **二级菜单**：鼠标悬停下拉分类（男/女按服装类型展开）
- **适配建议**：英文菜单 Home / Shop ▾ / Women ▾ / Men ▾ / Accessories ▾ / Brands ▾ / Sale / Events

## 四、首页 Hero

- **形式**：全屏轮播，大图 + 文案叠加
- **图片**：高端高尔夫服饰模特生活照
- **文案**：超大韩文标题（白色/黑色），关键词如 "Summer Clearance"、折扣百分比
- **强调色块**："30%" 使用荧光绿大字
- **左下角**：01/02 轮播分页
- **CTA**：DETAIL VIEW / SHOP NOW 类文字链接
- **适配建议**：做同样全屏轮播，英文大标题，黄/绿折扣数字，保留分页

## 五、首页下方模块（长图可见）

1. **新品/推荐商品横向滚动条**：4 个产品一组，左右箭头切换
2. **品牌墙**：一行品牌 Logo（GFORE / ICEBERG / Malbon / MARK & LONA / PEARLY GATES 等）
3. **更多商品网格**：多组 4 列产品卡片
4. **订阅区**：邮箱订阅或促销信息
5. **SEO 文案区**：大量韩文品牌介绍/购物说明（用于 SEO）
6. **Footer**：链接、版权、客服等

## 六、商品列表页

- **Filter Bar**：三个下拉筛选（品牌 / 颜色 / 商品特性），下划线样式
- **网格**：4 列产品卡片
- **卡片结构**：
  - 浅灰背景产品图（居中，白底/灰底）
  - 左上角双 Badge：**NEW**（绿色/青色背景）+ **해외배송** 海外配送（紫色背景）
  - 货号小字：GF410 / LC2621
  - 品名：全大写英文，紧凑排列
  - 价格：粗体 ₩999,999
- **加载方式**：Load More 按钮（无限加载）
- **适配建议**：美元 $XXX.XX；badge 改成 NEW / FREE SHIP；保留 Load More

## 七、商品详情页

- **布局**：大图占据上半屏，下方标题与信息
- **产品图**：浅色背景，服装正面大图居中
- **信息层级**：
  - 小字分类名 T-SHIRTS
  - 超大粗体品名：26SUMMER LONGSLEEVE POLO MEN-WHITE
  - 价格、选项（颜色/尺码）、加入购物车、描述等（首屏未显示）
- **适配建议**：保留"大图+分类小字+大标题"的视觉冲击，SKU 选择器做成极简下拉

## 八、通用交互元素

- **悬浮 Kakao 聊天按钮**：右下角黄色气泡图标（韩国特色客服）
- **适配建议**：换成国际通用的 WhatsApp / Messenger / 邮件客服浮动按钮，或隐藏

## 九、针对 WebShopp 的改造建议

| 原站元素 | 海外版改造 |
|---------|-----------|
| 韩元 ₩ | 美元 $ / 多币种 |
| 韩文内容 | 英文为主，可保留韩语为辅 |
| Kakao 客服 | 邮件/WhatsApp 客服 |
| 国内配送 태그 | Free Shipping / International Shipping |
| 韩国品牌名 | 保留品牌字段，用户可自行替换 |
| YouTube 直播预告 | 可替换为促销横幅 |

## 十、落地优先级

1. 首页 Hero 轮播 + 荧光黄公告栏 + MK 风格 Header
2. 品牌 Logo 墙
3. 4 列商品卡片（badge / 货号 / 大写标题 / 价格）
4. 筛选栏 + Load More 列表页
5. 产品详情大图页
6. 底部 SEO 文案区 + Footer
